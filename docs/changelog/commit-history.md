# Реестр истории коммитов YANIME

Этот файл фиксирует собственные изменения форка и синхронизации с Helandy/YummyTV.
Полная исходная история оригинала сохраняется в Git и доступна в
[Helandy/YummyTV](https://github.com/Helandy/YummyTV/commits/main).

## Правила ведения

- Добавляй запись для каждого собственного коммита после его создания.
- Для каждого коммита указывай дату, полный SHA, категорию и краткий заголовок.
- Не переписывай и не дублируй историю upstream: указывай базовый SHA оригинала и диапазон upstream-коммитов, включённых в синхронизацию.
- Если upstream-изменение пришлось адаптировать, укажи SHA оригинального коммита, свой адаптационный коммит и кратко — что было адаптировано и почему.
- При переписывании истории обновляй SHA собственных коммитов в этом файле. Не удаляй записи о происхождении адаптаций.
- Коммиты `[INTERNAL]` остаются в реестре, но не включаются в пользовательские release notes.
- Пользовательские пункты релиза дополнительно поддерживаются в `yanime.json`; этот реестр не заменяет changelog.
